# 统一画风指南（style-guide）

> 全 kind 共用的画风段（`STYLE_SEG`）。它参与去重键（`build_dedup_key` 的
> `style` 实参与 prompt**必须**同一字符串），定稿后**冻结用词**；
> 改一词等于全量缓存失效、全量重新付费。

## 决策依据

- ADR-0005 §6：「背景不含人物、统一画风/比例」——跨主体一致性是规格要求，
  也是教学场景的刚需（同一课文的场景图与人物图出现在同一页面，风格割裂非常显眼）。
- 现行 `DEFAULT_STYLE = "写实"` 只有一个词。写实对语文课文是安全默认：
  黏土风/3D 渲染/赛博国潮这类强风格会喧宾夺主，且对老课文容易混入
  时代错位元素；真实感插画在「课堂沉浸」与「忠实原文」之间最平衡。
- 用「**插画**」而非「照片」：provider 审核对「写实照片 + 人物」的真人像
  判定更敏感，插画形态可降低 `real_person` 类拒绝率。

## STYLE_SEG（v1 定稿稿）

模板骨架（统一在任何 prompt 尾部、构图尾巴之前）：

```
{基调}油画质感插画风格，柔和自然光，{配色}色调，背景层次分明，适合中学课堂展示
```

插槽取值约束（参与去重键的是**整段渲染结果**，不是插槽位）：

| 插槽 | 取值域 | 默认 |
|------|--------|------|
| 基调 | `写实的` / `连环画式的` / `水墨意境的` / `水彩绘本的` | `写实的` |
| 配色 | 按课文情绪基调给一个词：<br>严肃/历史题材=`低饱和暖褐`；<br>乡土/童年=`暖黄绿`；<br>战争/牺牲=`冷灰蓝`;<br>童话/意境=`青绿浅碧` | `低饱和暖褐` |

### 组装样例（即最终进 prompt 的字符串）

- 默认（乡土课文，如《故乡》《社戏》）：
  `写实的油画质感插画风格，柔和自然光，暖黄绿色调，背景层次分明，适合中学课堂展示`
- 历史题材（如《石钟山记》《六国论》配图）：
  `写实的油画质感插画风格，柔和自然光，低饱和暖褐色调，背景层次分明，适合中学课堂展示`
- 意境课文（如《桃花源记》《小石潭记》）：
  `水彩绘本的油画质感插画风格，柔和自然光，青绿浅碧色调，背景层次分明，适合中学课堂展示`

> 「油画质感插画」是有意混成的词：给 provider「手绘、非照片」的信号，
> 又保留写实光影。纯「油画」对中学生过重，纯「插画」偏平面。
> 定稿前先跑一次真实 provider（gpt-image-1 或百炼 wanx）看渲染倾向再冻结。

## 与去重键的关系（务必先读 imagegen/README.md §1）

- `build_dedup_key(style=…)` 的实参 = **整段渲染后的字符串**，
  `_Picked` 不再感知插槽结构；
- STYLE_SEG 任何字词变更都应视为「换 provider_version」级变更，
  走 `SceneDesigner.provider_version` bump，不要原地改 style 语义。
