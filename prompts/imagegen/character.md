# 人物头像 / 立绘 prompt 模板（character）

> `AssetKind.AVATAR`（1:1，512×512 理想 → 1024×1024 档位）与
> `AssetKind.FULLBODY`（3:4 竖版，768×1024 → 1024×1536 档位）。
> 头像每角色一次、跨场景复用（ADR-0005 §6）；#47 评审教训：
> **FULLBODY 的尾巴绝不能带「不出现任何人物」**。

## 前置缺口（截至 2026-10-30 的阻塞）

现行人物 prompt 的唯一输入是 `CharacterProfile.public_background`——
**没有外貌字段**。原文明示的外观（如少年闰土「紫色的圆脸，头戴一顶小毡帽，
颈套一个明晃晃的银项圈」）无处置放，生成结果靠模型从身份词猜。
接入方案：`character_design` v3 在输出契约增加 `appearance` 字段：

```
appearance: {
  face:       面部特征（脸型/脸色/神情，仅原文可推断，未写明处「原文未交代」）
  hair:       发式发型
  clothing:   服装（时代典型款式优先原文）
  accessories: 配饰/道具（原文点名的器物：项圈、毡帽、竹杖…）
  build:      体格体态
}
```

忠实性纪律沿用 boundary_rules：「原文可推断，未交代处如实写」；
**禁止为了画面好看补写细节**——课文插图形象是几代学生的共同记忆，
外貌偏离 = 教学方法性事故。

## 模板

### AVATAR_TEMPLATE（v1）

```
{era}的{expression}的{role_label}半身像，{face}，{hair}，{clothing}。
{accessories}。
{STYLE_SEG}，角色头像，半身正面，纯色简洁背景，无文字无 logo。
```

### FULLBODY_TEMPLATE（v1）

```
{era}的{role_label}全身立绘，{build}，{clothing}，{accessories}。
姿态：{pose}。神情：{expression}。
{STYLE_SEG}，角色全身立绘，直立全身，简洁背景，无文字无 logo。
```

### 插槽来源

| 插槽 | 现行 | 建议（v3 后） |
|------|------|--------------|
| `era` | 无 | dossier `era_setting` / 衣食器物层投影 |
| `role_label` | 无显式 | `TextAnalysis` 人物的 role（如「农民少年」「私塾先生」） |
| `face/hair/clothing/accessories/build` | ❌ | `appearance` 五字段 |
| `expression` | 无 | 目标场景情绪（运行期立绘）或默认沉稳 |
| `pose` | 无 | 该角色最具代表性的动作（personality_traits[].behavior 里行为化描述的一行投影） |

注意：`{face}` 等槽位「原文未交代」时**必须显式降级**为一个通用但带时代感的
中性词（如由中国时代风格统摄），不得把「原文未交代」四字直接送 provider。
头像模板把 `{expression}` 合进头像主句（正面、神情沉稳），不单设槽位；
`{pose}` 只在立绘模板出现，缺省时用该角色 `behavior` 里最具代表性的一行动作兜底。

## 真实课文样例（fixture 候选）

### 样例 1：少年闰土（头像，《故乡》）

```
民国初年浙东的腼腆而明亮的农家少年半身像，紫色的圆脸、头戴一顶小毡帽，
颈上套一个明晃晃的银项圈。
写实的油画质感插画风格，柔和自然光，低饱和暖褐色调，
角色头像，半身正面，纯色简洁背景，无文字无 logo。
```

### 样例 2：闰土（立绘，《故乡》中年版本）

```
民国初年浙东的饱经风霜的中年农民全身立绘，身材增加了一倍，
灰黄多皱的脸与松树皮般的手，穿一件极薄的旧棉衣。
姿态：手提长烟管，肩扛行李，运盐归来。神情：眼睛周围肿得通红，像石像一般。
写实的油画质感插画风格，柔和自然光，低饱和暖褐色调，
角色全身立绘，直立全身，简洁背景，无文字无 logo。
```

### 样例 3：藤野先生（头像，八上）

```
二十世纪初日本的黑瘦而不修边幅的医学教授半身像，黑瘦，留着八字须，戴着眼镜，
穿着褪色的旧和服，衣着随性不计较修饰。
写实的油画质感插画风格，柔和自然光，低饱和暖褐色调，
角色头像，半身正面，纯色简洁背景，无文字无 logo。
```

（样例刻意保留「随性不计较修饰」这类由「不拘小节」直译来的间接表述，
作为「character书写语需要向画面语转写」的对照——
渲染函数应把它磨成「衣着旧而整洁感弱」的画面语。）

## 「原文未交代」的兜底策略（设计稿中最易翻车处）

模型不能空槽，真实课文大量人物（配角的父母、仆人、先生）原文外貌为空白。
策略（写进 v3 prompt 侧约束，供设定的 appearance 字段直接填）：

1. **可从插图/时代推**：「原文未交代外貌；按{朝代}{身份}的常见形象」
   → 渲染函数翻译为「符合{era}{role_label}的典型形象」；
2. **画面需要但原文绝无**：只给最小安全集（性别、年龄段），年龄古文
   「老者/童子」可继续用，具体五官留白给模型；
3. **严禁**补写原文之外的辨识性细节（具体五官、明显时代错位的服饰），
   也严禁为了画面丰富把无关文化元素混进来——出错的根源通常不是模型画力，
   而是填槽人（设定 LLM）塞进了课文外的形象设定。

## 与现行 prompt 的兼容

现行的 `_KIND_TAILS[AVATAR/FULLBODY]` 与本模板尾巴段一致——接入时「
尾巴不变、描述主体从 public_background 换成模板」即可。description 参与
去重键：同一角色的 prompt 变了 → 新图、旧图仍留——教师端可从两种
生成结果中挑好的一张（删除操作走 #49 的 asset_ops 不删物理件）。
