# 场景背景 prompt 模板（background）

> `AssetKind.BACKGROUND`（16:9，1280×720 理想，provider 档位映射到
> 1536×1024）。规格硬约束（ADR-0005 §6）与现行尾巴保持一致：
> **画面中不出现任何人物**。

## 模板

### BG_TEMPLATE（v1）

```
{era}，{location}的空镜场景，{time}，{weather}。
画面表现：{action_summary}。
{mood}的总体氛围。{STYLE_SEG}，环境插画，画面中不出现任何人物，无文字无 logo。
```

### 插槽与供给来源（对照 imagegen/README §2 的缺口表）

| 插槽 | 语义 | 现行供给 | 建议供给（待接入） |
|------|------|---------|------------------|
| `era` | 时代一句话（器物/服装/建筑基调） | ❌ 无 | dossier `era_setting` 物理环境层投影 |
| `location` | 具体地点 | 从 beats 推断（不稳定） | `divide_events` v3 scene.visual_notes |
| `time` | 时段（清晨/黄昏/深夜…） | 无 | visual_notes |
| `weather` | 天气/环境（雨/雪/月色…） | 无 | visual_notes |
| `action_summary` | 本场剧情的环境侧剪影 | `scene_visual_description`（beats 拼接） | 保留——它已参与去重键，换来源=重付 |
| `mood` | 情绪基调词 | 从 beats 里的抒情词撞 | visual_notes |

**关键**：`action_summary` 若换来源，「与 Stage2/Stage3 同 prompt」和
缓存即破——action_summary 保留现行的 beats 拼接产物，
新字段（visual_notes 等）只填**前端缺口**，尾巴与描述主体不变。

## 范式说明

为什么要 slot 化而非继续裸拼 beats 文本：

- beats 文本含**人物动作与对白概要**（「少年闰土举钢叉讲看瓜刺猹」），
  直接送生图会把人物长回来——slot 化后 action_summary 规定只收
  「环境侧描写」（事件对环境的改变：踩乱的雪地、洒落的月光），人物词
  在渲染函数里做机械剔除/改写（丢弃动作句、保留环境句）；
- era/time/weather 是文生图非常吃信心的字段，必须显式给，
  「省略时默认现代背景」不可接受。

## 真实课文样例（fixture 候选）

### 样例 1：《故乡》（人教九上）——「月下看瓜刺猹」

```
民国初年浙东乡村，海边的十五年前沙地瓜田空镜场景，月夜，深蓝夜空与银白月光。
画面表现：一望无际的碧绿西瓜地，深蓝夜空挂一轮金黄圆月，沙地边有守瓜的简易草棚与斜立的木叉。
宁静而有生机的乡野氛围。写实的油画质感插画风格，柔和自然光，低饱和暖褐色调，
背景层次分明，适合中学课堂展示，环境插画，画面中不出现任何人物，无文字无 logo。
```

（era 槽与 location 槽的分界：第一句逗号前是时代，其后到「空镜场景」
为止是地点；「浙东」属地点信息——样例保留了口语化的实际效果，
渲染函数不必机械拆词，但插槽语义按上表执行。）

## 截断行为

`build_generation_prompt` 预算内截断的是**描述主体**（action_summary 段），
STYLE_SEG 与构图尾巴**总是完整保留**——接入 slot 模板后，渲染函数须保持
该不变量（现行实现的 `budget = max_chars - len(suffix) - len(separator)` 逻辑
平移到 `{mood} {STYLE_SEG} {tail}` 段上即可）。
