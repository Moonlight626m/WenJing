# 演出模式（/demo）与答辩操作手册

演出模式是给答辩、路演用的一条离线演示线：剧本和每一句台词都提前编排好，前端照台本把游戏演一遍。
画面用的是真实游玩页的同一套组件（`GameScreen`），只是消息不从后端来，而是由前端的「演出导演」按台本灌进 gameStore。
所以它不需要登录、不需要后端，也不需要网络。

真实系统的演示（老师生成剧本、学生连真模型游玩）仍然走 `/teacher` 和 `/game`，和这里互不影响。

## 入口与流程

- `/demo`：开卷标题页。点一下画轴展开，再点一下进入书匣。
- 书匣：一卷一张卡。现在有两卷：《少年闰土》（初中，白话）和《鸿门宴》（高中，文言）。
- `/demo/runtu`：你演「我」。还原五场，第五场「正月离别」是命运抉择；然后进入续写，三个续写目标全部达成后进入结局。
- `/demo/hongmen`：你演项羽。还原五场，第四场范增第三次举玦是命运抉择（默然不应 / 点头 / 向沛公举杯），
  三条路各有一段不同的席间变故；续写是宴罢当夜，亚父要走、叔父不语、樊哙那一问还没答，三个目标都达成后进入结局。

两卷都是三个结局。台词以课文原文为准，原文里没有的部分照人物口吻补写；《鸿门宴》里补写的是浅近文言，每段原文后面跟一句白话旁白，台下听得懂。

## 现场操作

| 操作 | 键 |
|---|---|
| 下一句（跳过当前等待，正在打字就一次打完） | 空格 / → / PageDown |
| 暂停、继续 | P |
| 平行世界：回到最近一次命运抉择 | B / PageUp |
| 选第 n 个选项 | 数字键 1–9 |
| 开卷、入卷、选角页开场 | 空格 / 回车 / PageDown |

翻页笔一般只发 PageDown、PageUp 和 B，正好对上「下一句」和「平行世界」。

舞台正上方的控制条上也有这几个按钮，并且一直标着「演示台本 · 预录」。
被问到这是不是录好的，照实说：台本是用真实系统跑出来、再人工整理过的，现场真连模型的演示另外进行。

续写阶段可以自己写一句话，也可以点「试试这样说」里现成的句子。
自己写的话是按关键词接到台本里最贴近的那一支（比如《少年闰土》里提到「水生」「宏儿」就接到两个孩子交朋友那一段，
《鸿门宴》里提到「叔父」「报信」「张良」就接到项伯认错那一段），都不贴近时，闰土会说一句「非常难……」，
范增会说一句「明日如何向诸侯交代」，目标不算达成。
这一点和真模型不同，请老师现场出题时心里有数。

## 彩排前

1. 用生产构建跑，没有开发角标，动画也更顺：`cd frontend && npm run build && npm start`，然后打开 `http://localhost:3000/demo`。
2. 书匣页底部有「清空结局图鉴（彩排用）」。正式开场前点一下，结局图鉴从 0/3 开始。
3. 投影电脑性能差时，在舞台顶栏把特效切到「简洁」。
4. 提前录一段完整演示视频放在桌面备用。

## 建议的演示路线（约 8 分钟）

| 时长 | 内容 |
|---|---|
| 0:30 | `/demo` 开卷，一句话讲清产品做什么 |
| 1:00 | 切到老师端，看一份已经生成好的剧本和配图审阅 |
| 3:00 | 《少年闰土》：选角 → 还原，演到命运抉择，选「许他一个约定」 |
| 1:30 | 续写：请老师出一句话，或点现成的句子，看目标一个个打勾 |
| 1:00 | 结局「海边的路」，印章、结局图鉴；按 B 回到抉择点，换「送画册」，说明平行世界 |
| 1:00 | 打开剧情回顾的「原文」页，讲教学价值收尾 |

时间够的话，接着演《鸿门宴》，展示同一套玩法换到文言课文上（约 5 分钟，可以多按空格快进）：

| 内容 | 怎么选 |
|---|---|
| 鸿门谢罪 | 选课文里的「此沛公左司马曹无伤言之」。第一幕结尾会接上「沛公至军，立诛杀曹无伤」，这是第 7 句原句，拾齐 7 句才有「拾遗」印 |
| 举玦舞剑（命运抉择） | 选「沛公，满饮此杯。前事一笔勾销。」 |
| 续写 | 三个目标：留住亚父、问出谁走漏了消息、回答樊哙那一问。第三个最值得讲：课文里项王「未有以应」，这里由学生来答 |
| 结局 | 「鸿门一诺」。按 B 回到举玦，换「默然不应」，演到「拾玉」 |

## 加角色立绘

现在台上的角色是竖排名牌。有了立绘，台上就是人物形象。

1. 用即梦、豆包或 Midjourney 生成全身像，提示词统一用一套风格，例如：
   `新国潮水墨插画，全身立绘，{角色描述}，纯色背景，低饱和，青碧与泥金点缀，电影感光影`
   - 闰土：十一二岁的海边少年，紫色圆脸，头戴小毡帽，颈上套明晃晃的银项圈，手捏钢叉。
   - 我：十一二岁的城里少爷，穿长衫，好奇的神情。
   - 母亲：清末江南主妇，和善。
   - 忙月：清末江南农人，粗布短衣，疼儿子的神情。
   - 项羽：秦末楚军统帅，二十多岁，身形高大，玄甲朱袍，眉目英武，神情骄傲。
   - 范增：七十岁的谋士，白须，深色长袍，腰间佩一枚玉玦，目光锐利。
   - 项伯：中年楚将，便服，神情犹疑。
   - 刘邦：五十岁上下，长须，便服，面带谦恭的笑。
   - 张良：清瘦文士，素色长袍，沉静。
   - 樊哙：魁梧武士，怒目，头发上指，左手持盾，右手按剑。
   - 项庄：年轻楚将，轻甲，持剑。
2. 去掉背景，存成透明 PNG，放到 `frontend/public/demo/<slug>/`。
3. 在对应的台本（`frontend/src/lib/demo/scripts/runtu.ts` 或 `hongmen.ts`）里加上 `portraits`，
   比如 `portraits: { 闰土: "/demo/runtu/yuntu.png" }`。
   导演会把它登记成角色的全身立绘，舞台按「立绘 → 头像 → 名牌」的顺序取用。

场景背景也可以照同样的办法换成生成的图片，改 `backgrounds` 里的路径即可。
现在的背景是 `scripts/demo-art/` 下的脚本生成的矢量图（`gen_runtu.py`、`gen_hongmen.py`，公共的笔墨在 `ink.py`），
改了脚本重跑一遍就能更新，例如 `python3 scripts/demo-art/gen_hongmen.py frontend/public/demo/hongmen`。

## 加一卷新剧本

1. 照 `frontend/src/lib/demo/scripts/runtu.ts` 或 `hongmen.ts` 写一份台本：剧本包（角色、场景、原文证据）加上一张节点图。
2. 在 `frontend/src/lib/demo/catalog.ts` 的 `SHELF` 里加一行 `scroll(新台本)`。
3. 图片放到 `frontend/public/demo/<slug>/`。要用脚本画，就照 `gen_hongmen.py` 新写一个，公共的画布、渐变、山脊从 `ink.py` 取。
4. 命运抉择里照着课文走的那一项，标记要写成 `fate: "origin"`：「改写」印就是看这一项有没有被选。

台本里能用的「拍」见 `frontend/src/lib/demo/types.ts`：旁白（可带换场）、台词、拾句、续写目标、抉择（可标命运抉择、可开自由输入）、按标记分支、结局。
`我` 的话只在你选了、写了之后才说出口，其余原文里「我」说的话写进旁白，这和真实游戏一致。
